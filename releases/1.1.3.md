# Arches-containers tool (act) 1.1.3 Release Notes

## Bug Fixes and Enhancements

- Fixes `act import -p <project_name>` assuming the repository folder has the same name as the project. Named imports now discover exported configurations in hyphenated, custom-named, and nested repository folders.
- Accepts a hyphenated project name, such as `act import -p mariner-proj`, and resolves it to the canonical snake-case name `mariner_proj`. A unique repository folder name is also accepted when `--repo_path` is omitted.
- Keeps compatibility with older exported configurations that do not contain `project_repo_directory`. Resolution uses the exported project name and actual filesystem paths.
- Excludes timestamped export backups and folders whose names do not match their configured project names from discovery, preventing false duplicate matches.
- Reports ambiguous imports with the matching project names and repository paths so developers can select one using `-p <project_name> --repo_path <path>`.
- Improves import error messages with separate, indented sections for the expected configuration, checked path, suggested project names, and next steps. Close matches are suggestions only and are never imported automatically.

## Breaking Changes

None. Explicit `--repo_path` values continue to take precedence, and existing literal export folder names are preserved.

## Installation Instructions

Activate your environment and run:

```bash
pip install --upgrade arches-containers
```

## Updates Needed to ACT Configs

None. Existing exported configurations can be imported without adding or changing configuration attributes.
