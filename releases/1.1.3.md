# Arches-containers tool (act) 1.1.3 Release Notes

## Bug Fixes and Enhancements

- Fixes named imports from hyphenated, custom-named, and nested repository folders [#138](https://github.com/arches-containers/arches-containers/pull/138).

## Breaking Changes

None.

## Installation Instructions

Activate your environment and run:

```bash
pip install --upgrade arches-containers
```

## Updates Needed to ACT Configs

None. Existing exported configurations can be imported without adding or changing configuration attributes.

## Notices

- Python 3.9 and 3.10 will not be supported in the next minor release as they are no longer supported.
