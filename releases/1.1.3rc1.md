# Arches-containers tool (act) 1.1.3rc1 Release Notes

This is the first release candidate for 1.1.3, published for testing before the final release.

## Bug Fixes and Enhancements

- Fixes named imports from hyphenated, custom-named, and nested repository folders.
- Accepts hyphenated project names and unique repository folder names, resolving them to the canonical name in the exported configuration.
- Supports older exported configurations without `project_repo_directory`.
- Excludes timestamped export backups and mismatched export folders from discovery.
- Reports ambiguous imports with project names and paths, and provides suggestions for unmatched names without importing them automatically.
- Formats import errors into separate, indented sections with actionable commands.

## Installation Instructions

Activate your test environment and install this exact candidate:

```bash
pip install --upgrade "arches-containers==1.1.3rc1"
```

Normal upgrades will not select this prerelease automatically.

## Testing

Test named imports using both snake-case and hyphenated names, custom repository names, nested exports, and older configurations without `project_repo_directory`. Check that incomplete names show suggestions and that duplicate exports require an explicit repository path.

No configuration updates are required. Existing import confirmation and hash options remain unchanged.
